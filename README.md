# Проект: Анализ лояльности клиентов (Afisha)

**Цель проекта:** Проанализировать поведение клиентов и оценить их лояльность на основе предоставленных данных.

**Основные этапы исследования:**
*   Изучение структуры данных (датафреймов).
*   Преобразование типов данных.
*   Исследовательский анализ данных (EDA) и визуализация.
*   Выявление паттернов поведения клиентов.

**Используемые библиотеки:** pandas, numpy, matplotlib, seaborn.
